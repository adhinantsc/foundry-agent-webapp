# RAKTA reference UI (from `reference docs/RAKTA Assistant.html`)

Supersedes `rakta-branding.md`. Rebuild the chat UI to match the reference design exactly, wired to the real Foundry agent.

## Decisions (2026-10-21)

| Topic | Decision |
|---|---|
| Elements with no backend | **Same layout, real data only.** Every panel is built in the reference style; content is real or comes from a config file. Nothing fake (no sample requests, callbacks, UAE PASS). |
| Language | **EN + Arabic**, full RTL, IBM Plex Sans Arabic, persisted per browser. Agent answers follow the user's language. |
| Theme | **Light only**, like the reference. Theme picker removed. |

## Reference → app mapping

| Reference element | Implementation |
|---|---|
| Splash (logo, gold bar, title) | Loading screen while sign-in + agent metadata load (min. display ~1.2 s) |
| Header: gradient navy, gold rule, white/gold logo | Same; logo extracted from the reference |
| Title + "Connected to …" status dot | Agent display name; "Connected to {Foundry agent}" green dot, red "Agent unavailable" on metadata failure |
| EN / عربي switch | Working language switch |
| History / New / Context buttons | Toggle left sidebar, new chat, toggle right panel |
| User initials avatar (gold) | Initials from the signed-in Entra account |
| Left sidebar: New conversation, search | Real; search filters loaded conversations |
| "Recent" list | Real Foundry conversations (title, relative time), delete on hover, load more |
| "Service directory" | Topic shortcuts from `config/assistant.ts` → send the topic as a question |
| Sidebar footer user + "UAE PASS verified" | Signed-in name + "Signed in with Microsoft Entra ID", plus a menu: export, shortcuts, settings |
| Grid-pattern main background, sub-header with title + session ref | Conversation title (first user message), conversation id in mono, "Give feedback" (session feedback) |
| Hero card with animated routes art | Same art; greeting with first name + time of day; agent description; pills: "Connected" + model name |
| "Start with a service" cards | Config topics (code, label, description) → send question |
| "Continue where you left off" | Three most recent real conversations → open them |
| "Popular questions" | Foundry starter prompts (fallback: config list) |
| Date divider | "Today · HH:MM" of first message |
| User bubble (gradient) + time | Same, keeps attachments + edit-last-message |
| Typing card "Checking service catalogue" | Shown until first token; label follows tool use (searching files, running code, calling a tool) |
| Bot card: "R" avatar, name, time, white card | Same; content is the agent's Markdown (tables, lists, code, citations) |
| Chips / permit / steps / tracker blocks | Not generated by the agent (Markdown only) → not rendered |
| Footer: source badge, copy, regenerate, 👍 👎, "Feedback received" | Source: "Sources: n" when citations exist, else agent name. Thumbs open the feedback modal |
| Feedback modal (1–5, reasons, comment, contact consent) | Same; sent to Application Insights (`answer_feedback` / `session_feedback`) |
| Session survey popup | After the first completed answer + 60 s, once per session |
| Composer: quick chips, textarea, attach, voice, hint, Send | Same; plus Stop while streaming, file previews, queued messages, paste/drag files, edit mode |
| Disclaimer under composer | Same text pattern, i18n |
| Right panel "Service context" | **Session**: agent, model, conversation ref, messages, tokens used, last response time; **About this assistant**: description; **Need a person?** only if a contact URL/phone is configured |
| Toast | Same style; copy, feedback, errors |
